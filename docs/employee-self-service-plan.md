# Employee self-service implementation

Authenticated organization members linked to employee records can access their own finalized performance reviews, career review requests, leave requests, onboarding tasks, and development plans. Employee progression submissions are recorded as unverified evidence; employment decisions are made only by authorized HR reviewers. Final performance-review acknowledgement is receipt only, not agreement.

HR owners/admins can link an existing account where its login email matches the employee work email in the same tenant. This requires prior membership provisioning. Employee leave requests are stored as pending and require separate human HR approval; no leave balance calculations or Sage payroll writebacks occur.

Remaining: self-service account invitation, secure email verification, appeal reviewer assignment, notifications, configurable leave balances and statutory rules, private document uploads, accessibility and native application verification, POPIA/legal sign-off and production security testing.
